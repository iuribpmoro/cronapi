March 31, 2026
v0.9.0 Feature

Uptime monitoring & structured error alerting

New monitoring infrastructure tracks job health and surfaces structured error data through the dashboard and status API.

  • ● Added /status endpoint exposing active job count, next scheduled run, and most recent failure detail
  • ● Structured error alerting — failed executions include HTTP status code, error message, and job ID in webhook alerts
  • ● Uptime tracking added to /health response; includes database and scheduler status
  • ● Fixed an edge case where scheduler reported running status incorrectly on cold start
March 28, 2026
v0.8.0 Fix Improvement

Stripe webhook reliability improvements

Fixed webhook signature verification and subscription line item expansion that caused paid plan activations to fail intermittently.

  • ● Raw body now captured before JSON parsing for correct Stripe HMAC signature verification
  • ● Expanded line_items in checkout.session.completed handler — fixes plan not activating after payment
  • ● Added notify_url and retry_count columns to job executions schema for richer failure tracking
March 22, 2026
v0.7.0 Feature

Web dashboard — job management UI

A full web dashboard for managing cron jobs without the CLI. View job status, execution history, and pause or delete jobs from the browser.

  • ● Job list view with real-time status indicators (active, paused, failing)
  • ● Per-job execution history with HTTP status codes, response bodies, and latency graphs
  • ● One-click pause and resume for individual jobs
  • ● Cookie-based auth session for dashboard — no API key required in browser
March 15, 2026
v0.6.0 Feature

HMAC request signing

Every outbound job request is now signed with an HMAC-SHA256 signature, allowing your endpoints to verify requests genuinely come from CronAPI.

  • ● Added X-CronAPI-Signature: sha256=<digest> header to all outbound job requests
  • ● Webhook secret configurable per-job via webhookSecret field on job creation
  • ● Added X-CronAPI-Execution-Id header for idempotency key support
  • ● Signature verification examples added to API docs for Node.js, Python, and Go
March 8, 2026
v0.5.0 Feature

Pricing plans & Stripe billing

Free, Indie ($9/mo), and Pro ($29/mo) plans with Stripe checkout. Paid plans unlock per-minute scheduling and higher job limits.

  • ● Free tier: 10 jobs, hourly minimum scheduling, 50-entry execution history
  • ● Indie tier ($9/mo): 100 jobs, per-minute scheduling, unlimited execution history
  • ● Pro tier ($29/mo): unlimited jobs, per-minute scheduling, priority support
  • ● Stripe Checkout integration with subscription management via customer portal
February 28, 2026
v0.4.0 Feature

Webhook retries with exponential backoff

Failed job executions are now automatically retried up to 3 times with exponential backoff. No lost executions from transient failures.

  • ● Automatic retry on HTTP 5xx, timeout, or connection error
  • ● Exponential backoff: retry 1 at 30s, retry 2 at 5m, retry 3 at 30m
  • ● Each retry logged separately with its own HTTP status and response body
  • ● No retry on HTTP 4xx — client errors indicate misconfiguration, not transient failure
February 1, 2026
v0.1.0 Launch

Initial release — schedule HTTP jobs via API

CronAPI launches in early access. Schedule HTTP requests on a cron schedule without managing cron servers.

  • ● REST API for creating, updating, pausing, and deleting cron jobs
  • ● Full cron expression support (5-field standard syntax)
  • ● Execution history with HTTP status, response body, and latency per run
  • ● API key authentication with cron_live_ prefixed keys
  • ● OpenAPI spec and interactive docs at /api/docs
